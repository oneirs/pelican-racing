# 晴湾海岸

当前交付是海滩赛道场景与自动巡游预览，尚未接入手动赛车操控、AI 对手或比赛判定。

- 路线：封闭 Catmull-Rom 样条，按弧长匀速巡游，约 211 米，路宽 12 米。
- 竞速布局：6 个发车位（2 列 × 3 排）、8 个有序检查点；发车网格移至较直路段。
- 地貌：环岛沙滩、分层浅海、中央草地。
- 地标：起终点棋盘门、灯塔、码头、小屋、棕榈树、遮阳伞、帆船。
- 视角：赛道全景、后方跟随，支持拖拽、缩放、自动环绕。
- 预览控制：暂停、速度倍率、回起点；小地图显示骑手位置与巡游圈数。

## 修改位置

- `src/world/track/route.js`：中心线控制点、道路高度与宽度。
- `src/world/track/race-layout.js`：6 人出生位置、朝向、检查点顺序和边界。
- `src/world/track/road.js`：路面、边线、路肩和起终点。
- `src/world/beach/terrain.js`：岛屿、浅海、沙滩与浪花。
- `src/world/beach/props.js`：棕榈树、灯塔等场景物件。
- `src/world/beach/batch.js`：静态物件按材质合并，减少绘制调用。
- `src/ui/minimap.js`：实时小地图。
- `src/main.js`：沿线路径移动和骑行动画。

几何路线与视觉赛道共用同一条中心线，后续玩家、AI 和检查点可以复用 `route.sample()`。
